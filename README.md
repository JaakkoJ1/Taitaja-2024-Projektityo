# Taitaja 2024 Semifinaali Projektityö

## Tekijät:

Jaakko (Front-end), Erik (Back-end)

## Tehtävä:

Semifinaalitehtävässä kilpailijoiden tulee rakentaa Tuottajamarket -verkkopalvelu, jonka kautta tuottajat voivat myydä lähiruokaa kuluttajille kotiinkuljetuksella. Semifinaalitehtävästä on nähtävillä myös arviointi- eli pisteytystaulukko.

## Asennusohjeet:

Lataa kaikki projektin tiedostot GitHubista - https://github.com/JaakkoJ1/Taitaja-2024-Projektityo/tree/main/tiedostot_final_v2

Siirrä tiedostot paikalliseen palvelinkansioon - (WAMP: www-kansioon, XAMPP: htdocs-kansioon)

Luo uusi tietokanta ja tuo mukana oleva verkkokauppa.sql-tiedosto - http://localhost/phpmyadmin/

Käynnistä palvelin käyttämällä WAMP- tai XAMPP-palvelinta (varmista, että Apache ja MySQL modelit ovat käynnissä, XAMPP:issa pitää käynnistää erikseen)

Siirry osoitteeseen: http://localhost/kansion_nimi/tiedoston_nimi ja nyt olet valmis käyttämään sivua selaimessa.
